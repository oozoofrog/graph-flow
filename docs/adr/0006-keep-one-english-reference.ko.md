# 0006 영어 원문 하나와 한국어 읽기본을 둔다

> 이 문서는 [0006-keep-one-english-reference.md](0006-keep-one-english-reference.md)의 한국어 읽기본입니다. 기준은 영어 원문입니다.
> 원문 해시: `sha256:abf0082bd785e0933edd04e04946ef8d06924ab3226ec7525b7a43f21ddaa537`. 영어 원문이 바뀌면 `scripts/tests/test_reading_copies.py`가 실패합니다.

상태: 승인됨(Accepted). 2026-11-20, PR #6 설계 검토.

## 배경

사람은 기준 문서를 영어로, 토론을 한국어로 하기로 정했습니다. 에이전트와 유지보수하는 사람이 같은 의무를 볼 때는 안정된 기준이 필요합니다. 통제된 기술 영어는 일관된 용어를 씁니다. [ASD-STE100](https://www.asd-ste100.org/STE_faq.html)

## 결정

기준 명세와 ADR은 짧은 기술 영어로 씁니다. 한국어 읽기본은 영어 초안 뒤에 만듭니다. 읽기본에는 원문 버전과 대응하는 ID를 적습니다. 읽기본마다 영어 원문의 SHA-256 해시를 적습니다. 해시가 지금의 영어 원문과 다르면 저장소 테스트가 실패합니다. 두 언어에서 요구의 강도를 같게 유지합니다. 지도의 이름, 설명, 선택지, 결과는 사람의 언어로 씁니다. 필요하면 원래 용어와 원문을 번역 옆에 둡니다. [CEM-R4](../spec/co-evolution-map.ko.md#cem-r4--사람의-언어로-쓰기)

## 검토한 대안

서로 독립된 두 명세는 뜻이 갈릴 때마다 어느 쪽이 기준인지 골라야 합니다. 영어만 두면 한국어 토론이 즉석 번역에 기대게 됩니다.

## 결과

한국어로 읽는 사람도 요구 하나를 ID로 짚어 반박할 수 있습니다. 영어 원문이 바뀌면 누군가 읽기본을 고칠 때까지 저장소 테스트가 실패합니다. 번역은 ID 비교와 함께 뜻 확인이 필요합니다. 빠진 글에는 명시적인 빈칸 표시를 붙입니다.

## 지키는 원칙

P1은 ID와 버전을 기계적으로 검사할 수 있게 합니다. P10은 사람의 언어로 근거 있는 결정을 내리도록 돕습니다. [원칙](../../skills/graph-flow/references/principles.md)
