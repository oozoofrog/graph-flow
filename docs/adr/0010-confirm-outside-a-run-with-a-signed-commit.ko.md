# 0010 실행 밖에서는 서명된 커밋으로 확인한다

> 이 문서는 [0010-confirm-outside-a-run-with-a-signed-commit.md](0010-confirm-outside-a-run-with-a-signed-commit.md)의 한국어 읽기본입니다. 기준은 영어 원문입니다.
> 원문 해시: `sha256:d89c6f366c76e08bbf7b4499943ffb57587b5b34258873a77e5d6c2c42e982bc`. 영어 원문이 바뀌면 `scripts/tests/test_reading_copies.py`가 실패합니다.

상태: 승인됨(Accepted). 2026-11-20에 사람이 OQ-6에서 이 선택지를 골랐습니다.

## 배경

뷰어는 실행이 없을 때도 동작합니다(ADR 0007). 작성한 항목은 Git에 있습니다(ADR 0008). 서명된 사람 답변은 실행 안에만 있습니다. 에이전트도 사람과 같은 저장소에 커밋합니다. [ADR 0003](0003-keep-link-confirmation-with-the-person.ko.md)

## 결정

실행 밖에서는 사람 자신의 키로 서명한 커밋이 항목을 확인합니다. 그 커밋은 항목의 상태를 "확인됨"으로 바꿉니다. `gf map check`는 사람이 관리하는 허용 서명자 목록으로 서명을 검증합니다. 실행 안에서는 지금처럼 서명된 답변이 항목을 확인합니다.

## 검토한 대안

실행 안의 자유 질문은 기존 서명 경로를 씁니다. 대신 확인할 때마다 실행이 있어야 합니다. 사람 전용 터미널 명령은 실행 없이 동작합니다. 대신 사람이 답하는 두 번째 경로가 생겨 따로 보안 검토가 필요합니다.

## 결과

답변 서명 형식은 바뀌지 않습니다. 사람은 서명 키를 한 번 설정합니다. 에이전트 세션은 그 키에 접근하지 못합니다. 쓸 때마다 암호나 손 접촉이 필요한 키를 씁니다. 에이전트의 커밋이 항목을 "확인됨"으로 바꾸면 `gf map check`가 실패합니다. 2026-11-20 기준으로 사람의 전역 Git 설정은 커밋에 서명하지 않습니다.
