## 배경

결정 픽스처는 처음 읽는 사람이 안내서를 따라 할 수 있는지 묻습니다. 이유와 승인 조건은 작은 회색 글씨로 나옵니다. 장식용 제목 글꼴 때문에 한국어 제목을 읽기 어렵습니다. 기울어진 버튼, 배경 격자, 줄무늬 카드가 질문에서 시선을 빼앗습니다. [이슈 #11](https://github.com/oozoofrog/graph-flow/issues/11)

## 결정

밝은 모드와 어두운 모드 모두 문서형 배치를 씁니다. 제목과 설명 모두에 한글과 라틴 문자를 지원하는 본문 글꼴을 씁니다. 결정, 이유, 근거, 버튼은 여백으로 나눕니다. 버튼은 기울이지 않고, 배경에는 무늬를 넣지 않습니다. 장식용 마스코트 그림은 뺍니다. 두 테마 모두 본문과 안내는 16 CSS px 이상, 글자 명암비는 4.5:1 이상으로 합니다. 시각적 강조는 질문, 상태, 동작에만 씁니다. 소요 시간 데이터와 관측 진단은 세부 정보에 둡니다. [DASH-R7](../spec/dashboard.ko.md#dash-r7--그래프와-진행-용어-설명하기) · [DASH-R14](../spec/dashboard.ko.md#dash-r14--읽기-쉬운-문서-형식-쓰기) · [DASH-R15](../spec/dashboard.ko.md#dash-r15--두-언어로-화면-문구-제공하기)

## 검토한 대안

어두운 그래프 테마를 유지하고 제목만 키우면 제목 크기는 나아집니다. 하지만 본문 명암비, 한글 글꼴, 촘촘한 묶음, 장식적인 버튼 문제는 그대로 남습니다.

## 결과

독자는 어느 테마와 언어에서도 같은 위계를 따라 읽습니다. 두 테마 모두 실제 한국어·영어 내용으로 캡처를 검토해야 합니다. 이름과 배치 경계는 프로그램이 확인합니다. 글꼴과 간격이 결정을 돕는지는 사람이 판단합니다. 대시보드는 운영체제의 테마 설정을 따릅니다(DASH-R14).
