# 0017 실행 밖 항목은 다음 실행에서 확인한다

> 이 문서는 [0017-confirm-out-of-run-items-in-the-next-run.md](0017-confirm-out-of-run-items-in-the-next-run.md)의 한국어 읽기본입니다. 기준은 영어 원문입니다.
> 원문 해시: `sha256:451fbcf5674f59ed09ccf890e66e62d59c79dab81a12f15f1a916b0bd529eaa3`. 영어 원문이 바뀌면 `scripts/tests/test_reading_copies.py`가 실패합니다.

상태: 승인됨(Accepted). 2026-11-20에 사람이 지도 OQ-8과 원격 OQ-4에서 이 선택지를 골랐습니다.

이 기록은 승인과 함께 [ADR 0010](0010-confirm-outside-a-run-with-a-signed-commit.ko.md)을 대체합니다.

## 배경

사람은 실행이 없을 때도 작성한 항목을 고를 수 있습니다. 뷰어는 제안을 정확한 버전 그대로 저장할 수 있습니다.
기존 사람 답변 경로는 실행 안에서 서명된 결정을 검증합니다. 계획 승인과 실행 종료는 이미 사람 단계입니다. [ADR 0005](0005-use-existing-human-slots-for-co-work.ko.md)

## 결정

실행 밖에서 고른 항목마다 그 프로젝트와 정확한 항목 버전으로 `pending confirmation` 대기열에 넣습니다.
다음 실행의 계획 승인이나 실행 종료 때, 리더는 대기 중인 버전을 선택 사항인 자유 질문 하나로 보여 줍니다.
항목, 버전, 이유를 각각 보여 줍니다. 항목마다 "확인"과 "대기 유지" 선택지를 주고, 미리 선택된 확인은 두지 않습니다.
사람은 로컬에서나 원격 화면에서 답할 수 있고, 질문 전체를 건너뛸 수도 있습니다.

질문 결합에 각 항목 참조와 버전을 넣습니다. 고른 항목 ID와 버전은 기존 서명된 답변 글에 기록합니다.
검증된 실행 안 답변이 고른 정확한 버전만 확인합니다. 인용한 출처가 바뀌면 CEM-R3의 철회 규칙을 그대로 적용합니다.
바뀐 항목은 새 버전에 대해 다시 확인해야 합니다. 건너뛰면 자격이 있는 항목은 대기 상태로 남고 실행은 계속됩니다. [CEM-R3](../spec/co-evolution-map.ko.md#cem-r3--연결의-출처-남기기) · [CEM-R6](../spec/co-evolution-map.ko.md#cem-r6--함께하는-방식을-기존-사람-단계에-얹기) · [RA-R7](../spec/remote-approval.ko.md#ra-r7--지도-확인-권한-제한하기)

## 검토한 대안

ADR 0010의 서명된 커밋에는 별도의 소유자 키와 서명자 허가가 필요합니다. 따로 서명하는 명령을 두면 사람 답변 경로가 하나 더 생깁니다.
일반 계획 승인은 개별 항목 버전에 대한 선택을 기록하지 않습니다.

## 결과

다음 실행이 없으면 그 버전은 대기 상태로 남습니다. 실행 밖에서 고르는 일은 결정을 만들지 않습니다.
지도에는 Git 서명 키가 필요 없습니다. 기존 서명기와 HMAC v3 형식이 로컬과 원격의 실행 안 답변을 모두 처리합니다.
정확한 버전에 대한 검증된 실행 안 답변 없이 "확인됨" 표시가 붙어 있으면 지도 검사가 실패합니다. [CEM-R14](../spec/co-evolution-map.ko.md#cem-r14--확인된-연결을-검사로-만들기)
