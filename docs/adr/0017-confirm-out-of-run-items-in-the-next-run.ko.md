# 0017 실행 밖 항목은 다음 실행에서 확인한다

> 이 문서는 [0017-confirm-out-of-run-items-in-the-next-run.md](0017-confirm-out-of-run-items-in-the-next-run.md)의 한국어 읽기본입니다. 기준은 영어 원문입니다.
> 원문 해시: `sha256:fabfef8fdcbed3d21b18be4d575e27c5571b09850ccdf5c7a6ea4993eef456ae`. 영어 원문이 바뀌면 `scripts/tests/test_reading_copies.py`가 실패합니다.

상태: 승인됨(Accepted). 2026-11-20에 사람이 지도 OQ-8과 원격 OQ-4에서 이 선택지를 골랐습니다.

이 기록은 [ADR 0010](0010-confirm-outside-a-run-with-a-signed-commit.ko.md)을 대체합니다.

## 배경

사람은 실행이 없을 때도 작성한 항목을 고를 수 있습니다. 뷰어는 제안을 정확한 버전 그대로 저장할 수 있습니다.
기존 사람 답변 경로는 실행 안에서 서명된 결정을 검증합니다. 계획 승인과 실행 종료는 이미 사람 단계입니다. [ADR 0005](0005-use-existing-human-slots-for-co-work.ko.md)

리더가 쓴 자유 질문은 고른 버전과 다른 내용을 설명할 수 있습니다.

## 결정

고른 파일의 정확한 Git 버전과 SHA-256 내용 해시를 프로젝트 대기열에 고정합니다.
다음 계획 승인이나 실행 종료 때 리더는 `gf map present`를 실행합니다. 리더는 글을 하나도 제공하지 않습니다.
Graph-flow는 고정된 파일을 Git에서 그대로 읽고, 사람의 언어로 된 고정 템플릿을 씁니다.
결정은 `issuer: map`과 `purpose: map_confirmation`으로 냅니다. 항목 ID와 내용 해시는 `evidence`에 묶습니다.
`gf decide ask`는 자유 질문 전용으로 둡니다. 새 purpose는 기존 HMAC v3 형식 안의 필드 값입니다.
각 화면에서 항목마다 확인, 대기 유지, 거절 선택지를 줍니다. 확인은 선택되지 않은 상태로 둡니다.
바뀐 파일은 `changed after selection`으로 표시합니다. 표시한 뒤에 바뀌었더라도 확인을 거부합니다.
화면은 CEM-R6에 따라, 고른 동작과 정확한 버전으로 정규 답변 줄을 만듭니다.
지도는 검증된 결정에서 그 형식만 읽습니다. 거절된 버전은 이력에 남깁니다.
실행 종료 때 답하지 않은 묶음은 대체 처리로 기록하고, 그 묶음의 자격이 있는 버전은 대기 상태로 남깁니다.
건너뛰어도 대기 상태나 필수 답변이 늘지 않습니다. 인용한 출처가 바뀌면 미확인 제안은 여전히 철회됩니다.

## 검토한 대안

ADR 0010의 서명된 커밋에는 별도의 소유자 키와 서명자 허가가 필요합니다. 따로 서명하는 명령을 두면 사람 답변 경로가 하나 더 생깁니다.
일반 계획 승인은 개별 항목 버전에 대한 선택을 기록하지 않습니다.

## 결과

다음 실행이 없으면 그 버전은 대기 상태로 남습니다. 실행 밖에서 고르는 일은 결정을 만들지 않습니다.
지도에는 Git 서명 키가 필요 없습니다. 기존 서명기와 HMAC v3 형식이 로컬과 원격의 실행 안 답변을 모두 처리합니다.
검증에는 원래 설치본 키, 실행 기록, 프로젝트 위치가 필요합니다.
그 맥락을 쓸 수 없으면 영향받는 항목마다 `unverifiable here`로 이름을 밝힙니다.
잘못되었음이 드러난 주장은 지도 검사에서 실패합니다. [CEM-R14](../spec/co-evolution-map.ko.md#cem-r14--확인된-연결을-검사로-만들기)
